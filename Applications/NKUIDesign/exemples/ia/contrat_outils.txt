## 1. CE QUE L'OUTIL ACCEPTE -- la grammaire du document

Tu produis une INTERFACE pour NkUIDesign.

Demande : <la demande de l'utilisateur, en francais>

Reponds UNIQUEMENT par un document au format ci-dessous,
sans explication, sans balise de code.

REGLE ABSOLUE : n'ecris JAMAIS de position ni de coordonnee.
La position se calcule ; tu declares des tailles et un agencement.

Format :
nkuidoc 1
titre = <texte>
noeud <numero, en partant de 0 pour la racine>
  libelle = <texte>
  composant = <nom du catalogue, ou vide pour un cadre>
  enfants = <numeros de noeuds, separes par des espaces>
  largeur = <fixed | content | fraction | weight | expand> <valeur> <min> <max>
  hauteur = <idem>
  agencement = <none | row | column | grid | anchor | free>
  ecart = <px>
  marge = <px>
  colonnes = <n, pour la grille>
  alignement = <start | center | end | stretch>
  reglage param <nom> = <valeur>   (facultatif)
  reglage variante <nom>           (facultatif)

REGLE ABSOLUE : tout noeud autre que 0 doit apparaitre dans le champ
`enfants` d'exactement UN autre noeud. Un noeud que personne ne cite
n'existe pas : le document est alors refuse pour structure incoherente.
Le noeud 0 est la racine ; c'est lui qui cite les premiers.

Exemple complet et minimal :
nkuidoc 1
titre = Exemple
noeud 0
  libelle = Racine
  composant = 
  enfants = 1 2
  largeur = expand 1 0 0
  hauteur = expand 1 0 0
  agencement = colonne
noeud 1
  libelle = Titre
  composant = etiquette
  enfants =
  largeur = expand 1 0 0
  hauteur = content 24 0 0
noeud 2
  libelle = Valider
  composant = bouton
  enfants =
  largeur = content 0 0 0
  hauteur = content 32 0 0

N'emploie que des composants du catalogue ci-dessous.

## 3. CE QUE L'OUTIL REFUSE, ET AVEC QUEL MOTIF
# Un refus nomme est un OUTIL, pas une panne : un modele invente, c'est le
# cas normal. Chacun de ces motifs laisse le document INTACT.

refus le backend n'a rien rendu
refus aucun document lisible dans la reponse
refus nomme un composant que le registre ignore
refus ne se rejoue pas a l'identique
refus cible de greffe invalide

## 4. CE QUE L'OUTIL GARANTIT

garantie le document n'est touche qu'apres validation ET rejeu identique
garantie toute pose se retire d'un geste, document identique au bit
garantie une proposition ne touche pas le document avant sa validation
garantie chaque noeud pose porte sa provenance (auteur ia, origine nommee)

## 5. CE QUE L'OUTIL NE SAIT PAS FAIRE -- mesure, pas suppose

limite il ne recoit AUCUNE image : la requete porte trois champs, tous du texte
limite il ne sait que GREFFER un sous-arbre : ni renommer, ni deplacer, ni
       changer une propriete d'un noeud existant
limite deux composants du catalogue n'ont pas d'equivalent dans le vocabulaire
       du fichier d'interface : ils sont COMPTES et NOMMES, jamais devines
limite 16 roles du vocabulaire du format ne sont pas montes (ColorField,
       Column, ContextMenu, Drag, Flow, Grid, ImageButton, Menu, MenuBar,
       MenuItem, NumberField, RadioGroup, Row, Stack, Switch, Table). Leur
       CONTENU n'est plus perdu depuis le 17/09 -- il monte dans le flux du
       parent -- mais le conteneur est compte inconnu et le document REFUSE
       (mesure : 2 montes -> 6 et REFUSE -> MONTE pour Scroll, desormais monte)
limite le monteur ne peint l'apparence AU REPOS que sur Button, RepeatButton,
       Panel et Window (fond) et Text (encre). Un fill sur un role sans surface,
       radius, font, shadow et stroke sont COMPTES non peints, jamais devines
limite aucun etat d'apparence autre que le repos n'est applique : ce monteur
       monte l'etat au repos, il n'a ni souris ni focus
limite un Spacer sans size, dans une rangee, veut dire prends la place qui
       reste et n'est PAS honore : pousser le voisin jusqu'au bord demanderait
       deux passes. Il vaut zero (le voisin reste dedans) et la demande est
       COMPTEE. Avant le 17/09 il valait 120 px inventes et poussait le voisin
       HORS du panneau, montage vert
mesure  un compteur de DEBORDEMENT existe depuis le 17/09 : il nomme tout widget
       qui sort de la region de son conteneur. Il reste rouge sur deux familles
       non corrigees : un conteneur a sizeRel 1.0 pose apres une marge, et une
       HBox qui prend toute la largeur du parent depuis un curseur indente
