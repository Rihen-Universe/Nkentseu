NkFoundationSetLogSink

#
fonction
void NkFoundationSetLogSink(NkFoundationLogSink sink)

Définir un sink de log personnalisé

Thread-safe : l'assignation atomique d'un pointeur est garantie sur toutes les plateformes supportées. Pour une configuration thread-safe avancée, synchroniser l'appel à cette fonction.

Paramètres

NomTypeRôleDéfaut
sinkNkFoundationLogSinkPointeur vers la fonction de callback, ou nullptr pour le défaut
@codefragment, non compilé
// Définir un sink personnalisé au démarrage de l'application
NkFoundationSetLogSink(MyFileLogger);

// Réinitialiser vers le backend par défaut
NkFoundationSetLogSink(nullptr);
Source : NkFoundationLog.h, ligne 263
