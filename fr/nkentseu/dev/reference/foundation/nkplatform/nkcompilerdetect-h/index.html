NKENTSEU_COMPILER_MSVC

#
macro
#define NKENTSEU_COMPILER_MSVC

Macro de détection MSVC (Microsoft Visual C++)

Définie lorsque le code est compilé avec MSVC (Visual Studio). La version est accessible via NKENTSEU_COMPILER_VERSION (_MSC_VER).

@codefragment, non compilé
#ifdef NKENTSEU_COMPILER_MSVC
    // Code spécifique à MSVC
    #pragma warning(disable: 4100)
#endif

NKENTSEU_COMPILER_VERSION

#
macro
#define NKENTSEU_COMPILER_VERSION

Version numérique du compilateur

Format variable selon le compilateur : - MSVC : _MSC_VER (ex: 1930 pour VS 2022) - GCC/Clang : MAJOR*10000 + MINOR*100 + PATCH (ex: 110200 pour GCC 11.2.0) - Intel : __INTEL_COMPILER (ex: 2021 pour ICC 2021)

Retour

Valeur numérique représentant la version du compilateur
