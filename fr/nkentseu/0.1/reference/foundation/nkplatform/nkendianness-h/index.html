NkGetCompileTimeEndianness

#
fonction
constexpr NkEndianness NkGetCompileTimeEndianness()

Détection d'endianness à la compilation (API NK)

Cette fonction constexpr permet d'évaluer l'endianness à la compilation, permettant au compilateur d'optimiser les branches conditionnelles.

Retour

NkEndianness détectée via les macros du préprocesseur

NoteSur les plateformes courantes (Windows, Linux x86/ARM), retourne NK_LITTLE.
@codefragment, non compilé
if constexpr (NkGetCompileTimeEndianness() == NkEndianness::NK_LITTLE) {
    // Code optimisé pour little-endian
}
Source : NkEndianness.h, ligne 112
