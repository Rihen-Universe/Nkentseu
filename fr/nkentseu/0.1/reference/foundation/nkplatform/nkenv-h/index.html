NkMove

#
fonctiongénérique (template)

Déplacement générique d'une valeur (équivalent à std::move)

Permet d'implémenter la sémantique de déplacement sans dépendre de <utility>. Utilisé pour optimiser les transferts de ressources dans les conteneurs.

Paramètres

NomTypeRôleDéfaut
tT &Référence vers la valeur à déplacer

Retour

Rvalue reference vers la valeur déplacée

@codefragment, non compilé

NkEnvString str2(NkMove(str1));  // str1 est vidé, str2 prend possession

GetEnvVar

#
fonction
const char *GetEnvVar(const char *name) noexcept

Alias simple et LIABLE (header-only) pour lire une variable d'environnement

Paramètres

NomTypeRôleDéfaut
nameconst char *Nom de la variable (peut être nullptr -> retourne nullptr)

Retour

Pointeur vers la valeur (buffer géré par le CRT), ou nullptr si absente

NoteContrairement à NkGet (défini dans NkEnv.cpp, donc NON liable depuis une autre unité de traduction), cette fonction est définie inline DANS le header : elle est utilisable depuis n'importe quelle application. Elle enveloppe getenv (C standard, cross-plateforme Windows/POSIX) pour offrir un point d'accès dans le namespace maison.
@codefragment, non compilé
const char* steps = nkentseu::env::GetEnvVar("NK_GPT_STEPS");
if (steps) { ... }

NkPrependToPath

#
fonction
bool NkPrependToPath(const NkEnvString &directory, const NkEnvString &varName = NkEnvString("PATH"))

Ajouter un répertoire au début d'une variable de chemin

Le répertoire est préfixé avec le séparateur approprié. Si la variable n'existe pas, elle est créée avec le répertoire seul.

Paramètres

NomTypeRôleDéfaut
directoryconst NkEnvString &Chemin du répertoire à ajouter
varNameconst NkEnvString &Nom de la variable (défaut: "PATH")NkEnvString("PATH")

Retour

true si l'opération a réussi, false en cas d'erreur

@codefragment, non compilé

// PATH devient "/opt/myapp/bin:<ancienne valeur>"
