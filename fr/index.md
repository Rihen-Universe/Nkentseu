# La documentation de Rihen

Les projets de Rihen, documentés pour celles et ceux qui les utilisent.

- [Nkentseu](nkentseu/0.1/index.md)
- NKCode (à venir) : L'éditeur de code de Rihen, hors ligne, avec son assistant.
- NKCraft (à venir) : Modéliser en 3D, de la photo ou du texte à l'objet éditable.
- Noge et Nogee (à venir) : Le moteur de jeu et son éditeur.
- NkUIDesign (à venir) : Dessiner des interfaces, puis les faire tourner.
- Jenga (à venir) : Le système de construction multiplateforme.
- NKEditorKit (à venir) : Les composants des éditeurs de Rihen, réutilisables.
- Kits canvas (à venir) : Dessiner en 2D et faire des applications légères.
- Les jeux de Rihen (à venir) : Pour chaque jeu, un guide du joueur : commandes, règles, astuces, questions fréquentes.
